# Repository directory

Reviewed on 27 October 2026. Repository ownership and non-fork status are not proof of independent authorship.

## Web projects

- [arshad-finance-blog-01](https://github.com/Arshad9999/arshad-finance-blog-01): A React and TypeScript educational finance website with trading basics, tax guides, career resources, investment topics, and a blog page.
- [c-foundations-2025](https://github.com/Arshad9999/c-foundations-2025): A React and TypeScript learning website with C programming topics, questions, and a lab-program page. The repository contains the website, rather than a standalone C application.
- [google-cohort2-arcade25](https://github.com/Arshad9999/google-cohort2-arcade25): A React and TypeScript community information site with a calculator route and browser-local profile storage for the 2025 Arcade cohort.
- [pattern_recognition](https://github.com/Arshad9999/pattern_recognition): A React and TypeScript educational website covering pattern recognition paradigms, classifiers, clustering, dimensionality reduction, and a practical assignment page.
- [JaalNetra](https://github.com/Arshad9999/JaalNetra): A static HTML, CSS, and JavaScript project website with home, demo, download, documentation, help, and contact pages. Its branding refers to network analysis; the repository does not contain a working packet-capture backend.

The four React/TypeScript apps include Lovable-generated scaffolding. The Arcade site is historical and includes unfinished functionality. JaalNetra is collaborative and has missing local assets.

## Learning material

- [10-Image-Classification-using-CNN](https://github.com/Arshad9999/10-Image-Classification-using-CNN): A learning notebook exploring convolutional neural networks with TensorFlow and the ten-class CIFAR-10 image dataset.
- [6Companies30Days](https://github.com/Arshad9999/6Companies30Days): A collection of C++ interview practice solutions and problem notes for the #6Companies30Days challenge.
- [BigDataAnalytics](https://github.com/Arshad9999/BigDataAnalytics): Markdown study notes covering big data analytics, data mining, Hadoop, and distributed data processing.
- [google-cloud-arcade-2023](https://github.com/Arshad9999/google-cloud-arcade-2023): Study notes and challenge material collected for the 2023 Google Cloud Arcade seasons.
- [HSSMC-for-Engineers](https://github.com/Arshad9999/HSSMC-for-Engineers): Module-based study notes on engineering economics, Indian history, law, and sociology.
- [IoT-InternetofThings](https://github.com/Arshad9999/IoT-InternetofThings): Networking lab notes describing topologies and Cisco Packet Tracer exercises.
- [LetsLearnGit](https://github.com/Arshad9999/LetsLearnGit): A Git practice repository that also contains two Java exercises.
- [Machine-Learning](https://github.com/Arshad9999/Machine-Learning): Python lab exercises covering matrix operations, plotting, regression, classification, gradient descent, clustering, and neural-network forward propagation.
- [OpenGL-Vth](https://github.com/Arshad9999/OpenGL-Vth): Fifteen C++ OpenGL/FreeGLUT lab exercises covering lines, letters, shapes, animation, and 3D objects.
- [Python-Deep-Learning](https://github.com/Arshad9999/Python-Deep-Learning): Learning notes and partial Python implementations for introductory neural-network lab exercises. Some lab directories contain notes only, and LAB 03/code.py is empty.
- [PythonPlayground](https://github.com/Arshad9999/PythonPlayground): Small Python exercises for Armstrong numbers, factorials, Fibonacci sequences, prime numbers, and a notebook of printed patterns.
- [University-Notes](https://github.com/Arshad9999/University-Notes): A small notes repository containing workshop-practices material.

`6Companies30Days` has imported author history credited to Vortex-21/vortex-21 and should not be claimed as independently authored without further evidence.
